# 实验记录区

这里记录真实尝试，不区分成功或失败。

## 一篇实验记录应该满足什么

1. 说清楚你想验证什么
2. 记录做法，而不是只写结果
3. 说明观察到的现象
4. 写出结论和不确定性
5. 提炼出后续问题或下一步动作

## 建议命名

使用 exp-YYYYMMDD-主题.md

例子：

1. exp-20260525-react-vs-workflow.md
2. exp-20260525-memory-retrieval-granularity.md

## 这类内容特别重要

1. 失败实验
2. 结果不稳定的尝试
3. 和原先直觉相反的结果
4. 暂时没有结论，但暴露出关键变量的过程

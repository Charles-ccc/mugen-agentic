# 草稿层说明

草稿层是这个仓库的缓冲区。

它的目标不是保存所有原始聊天，而是用最低成本留下值得继续推进的线索。

## 什么时候放这里

1. 你有一个问题，但暂时还回答不了。
2. 你观察到一个现象，但还没有验证。
3. 你想做一个实验，但设计还不完整。
4. 你读到一个案例，觉得值得后续拆解。

## 不应该放什么

1. 原样粘贴的整段聊天记录
2. 没有后续价值的临时碎片
3. 已经足够清晰的问题卡片或实验记录

## 建议命名

1. 极短内容：先记到 [INBOX.md](INBOX.md)
2. 单独草稿：使用 draft-YYYYMMDD-keyword.md

## 离开草稿层的条件

满足任一条件，就应该被整理出去：

1. 已经能回答一个具体问题
2. 已经形成一次真实实验记录
3. 已经确认这条线索没有价值，可以删除

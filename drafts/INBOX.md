- [记忆] 长期记忆什么时候值得做，什么时候只是复杂化。下一步：先按收益、成本、污染风险三项拆开看。

## 待验证想法

- Agent 的真正分界不在“会不会调用工具”，而在“是否存在闭环决策与状态更新”。
- 很多记忆方案失败，不是因为存不下来，而是因为取回来的粒度和时机不对。
- 多 Agent 的收益经常被沟通成本和调试成本吞掉。
- 起步阶段最值得先做的，不是更强自主性，而是更强可观测性和更清晰回退路径。

## 候选实验

- 对同一个任务分别用单轮 prompt、固定 workflow、ReAct agent 处理，比较效果、成本和失败模式。
- 对同一个工具集合，分别提供“模糊描述”和“精确描述”，观察工具选择正确率是否变化。
- 对同一个知识任务，比较无记忆、会话摘要记忆、检索记忆三种方案的收益和噪音。
- 为同一个 Agent demo 设计 3 套不同评估样本，观察成功率是否明显波动。

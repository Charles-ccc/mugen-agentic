# 问题卡片区

这里存放一个问题对应一篇内容的问答卡片。

## 一篇问题卡片应该满足什么

1. 只回答一个具体问题
2. 能说明为什么这个问题重要
3. 给出当前答案，而不是只堆材料
4. 标出答案稳定程度
5. 尽可能链接相关实验或其他问题卡片

## 建议命名

使用 q-主题-问题关键词.md

例子：

1. q-boundary-what-counts-as-agent.md
2. q-memory-when-not-to-build-memory.md

## 状态建议

每篇卡片建议在文中标一个状态：

1. 初稿：已有初步答案，但证据还薄
2. 已整理：结构清晰，能帮助复盘
3. 已验证：已有实验、案例或多轮复用支持

## 不建议写成什么样

1. 一个文件回答很多问题
2. 全是摘录，没有自己的判断
3. 把未经验证的猜测写成确定结论
